Security limitations

This is a standalone HTML application. Its accounts and task data are stored in browser localStorage, so the sign-in screen is not a security boundary and does not protect shared data from someone who can access this browser profile or edit the file.

For genuinely secure multi-user access, host the app over HTTPS and move authentication, authorization, and shared task storage to a server-side backend. Do not use the built-in demo credentials for sensitive information. Account passwords are stored only as salted SHA-256 hashes (never plaintext) in this browser and in the shared database file — treat the shared folder as trusted, or host the app on a server for real security.
